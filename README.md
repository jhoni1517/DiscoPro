# Disco Pro 7.7.1

Cuidado completo do PC com Windows 10/11.

## Baixar
- **[DiscoPro.exe](https://raw.githubusercontent.com/jhoni1517/DiscoPro/main/DiscoPro.exe)** — o programa (um arquivo só, abre como administrador)
- **[DiscoPro_portatil.zip](https://raw.githubusercontent.com/jhoni1517/DiscoPro/main/DiscoPro_portatil.zip)** — pasta portátil para pendrive (exe + LEIA-ME)

Depois de instalado, o próprio Disco Pro procura versão nova ao abrir e oferece atualizar
(ou atualiza sozinho, se você escolher). Pela linha de comando: `DiscoPro.exe --atualizar`.

## Novidades da 7.7.1
• Impressoras › 'Voltar impressoras automaticamente': devolve impressora que sumiu ou ficou 'driver indisponível' (driver, porta e todas as configurações) a partir do ponto de restauração, sem restaurar o resto do PC.
• Corrigidas as datas dos pontos de restauração (31/12/1969).
• Modo protegido (desde a 7.7): o Disco Pro não mexe em sistema, drivers, impressoras e dispositivos.
